# 旺衰分析：先给依据，再给倾向

类型：传统命理分析工作法。知识版本：2（v0.6）。本文是项目自编的分析框架，不是历法事实或一套已验证的事件预测模型。

## 用户应先看到什么

用户不必先回答“我是身强还是身弱”才能获得解释。Agent 可根据完整盘面给出**偏强、偏弱、未定**中的一个初步倾向，并展示支持依据、相反依据和仍缺少的条件。身强不表示能力强、身体好或运气好；身弱也不表示能力差。这里讨论的是某种传统分析口径下，日主在原局中的承受与生扶关系。

应用 v0.6 会先给出本地规则初判，Agent 可以复核。`strength show` 返回本地 `report`；`context` 里叫 `nativeStrength`。该报告是 `ordinary-fuyi-v1.0` 普通扶抑筛查：保留月令、透干、根气、生扶与泄耗克的具体位置，只有规则条件方向一致时才给偏强或偏弱，不做总分或置信百分比。

本地规则主动保留未定的情况包括：未知时柱、候选盘、出生时刻处于时钟回拨的重复区间、距离交节不足产品规定的 10 分钟核对窗口，以及辰戌丑未杂气月、日干五合、完整三合三会、月令或根气所见六冲等结构争议。极端生扶／无生扶情况需要排除从格、专旺，也不会直接断成极强或极弱。10 分钟是产品校盘提醒范围，不是古法阈值。未定不等于中和。

程序判断具有明确口径和局限，并不是传统各流派共有的唯一算法。它没有完整建立司令分日、调候、合化、格局或喜用神系统；不得将本地标签、简单加权阈值或八个字的五行数量包装成完整判断。复核应读报告中的 `evidence`、`counterEvidence`、`uncertainties` 与 `limitations`，指出同意或不同意的具体理由。

## 证据组织

先读 `chart-conventions`，通过 CLI 取得四柱及口径。再按以下层次组织证据；不需要把每条术语都堆给用户。

1. **出生月令**：明确月支、节月和日主五行。月支本气对日主是同类、生扶、泄、耗还是克，是一条初始线索。不能把“得令”单项当成最终结论。辰戌丑未尤其不能仅因为本气属土就将全月视为同一种环境；未实现司令分日时应明示没有采用该层规则。
2. **通根与生扶**：列出具体哪一柱、哪一个藏干与日主同五行，是否为本气；再列其他天干的比劫与印。日干自身不重复计算成外来帮助。同五行藏干出现不等于该根始终强而有效；没有检出同类也不能忽略其他生扶条件直接断弱。
3. **泄耗克与结构**：识别食伤、财、官杀出现的位置，与生扶证据并列。考虑透干、距离、成组关系及是否有支持链条。不要把名称本身当成结果，例如见七杀即凶、见正印即吉。
4. **合冲是否改变解释**：CLI 返回配对关系不等于完成合化。列明冲到哪一支、合到哪一天干；若要主张合化、根气受损或力量改向，应说明采用的成立条件和依据。没有对应证据则保留原关系，不自动改五行。
5. **特殊条件**：从格、化气、调候和普通扶抑不是同一个问题。材料不足以判断时保留未定，或只给普通扶抑视角下的暂定倾向，避免同时套用相冲突的规则。

归纳时权衡证据的角色与相互关系，而不是给每一字统一加一分。主要证据相互冲突、时柱未知会改变结构、出生候选盘不唯一或存在关键口径争议时，未定是有效结论。多个候选都共有的线索仍可解释，但不要藏起差异。

## 输出与保存

建议给用户四项内容：

- **倾向与口径**：例如“普通扶抑视角下初步偏强”，或“目前未定”。
- **依据**：引用实际柱位和字段，说明哪些是应用直接计算、哪些是解释判断。
- **待核对**：相反证据、缺失时刻、边界或尚未验证的结构。
- **如何使用**：只把倾向作为后续十神与岁运解释的条件，不据此要求改名、消费、取消日程或作重大决定。

通过 `insights save` 保存，记录类型和 Agent 来源由接口设置，不额外传 `kind` 或 `source`；携带读取时的 `profileID` 与 `profileRevision`。可选字段 `strengthAssessment` 使用 `strong`、`weak`、`unspecified`；分别对应偏强、偏弱、未定。依据、口径和缺项写入正文。日常日笺没有分析旺衰时省略该字段，不沿用猜测。

分析结论不自动更改档案里的手动 `strengthAssumption`。应用采用「手动偏强／偏弱（`profile_override`）> 最新且版本匹配的 Agent 分析（`agent_insight`）> 本地规则（`local_rule`）」顺序。有效 Agent 分析为未定时保留未定，不再用本地标签填空。`context.strengthBasis` 标明实际采用的来源，本地报告始终可以单独查看。用户修改出生资料后，旧解读会标为过期，需要按新资料重新计算与分析；旧正文仍保留为历史内容。

## 岁运关系

先解释原局，再加入当前大运、流年、流月、流日的关系。当天偏财或七杀只是某层天干与日主之间的十神名称，不等于当天一定发生相应事件。强弱倾向也不应每天随流日改写成一份新的出生结论。

普通扶抑中常以生扶或泄耗克的角度解释不同承受条件，但不能因此直接给完整喜用神名单。调候、格局、从化和具体结构可能改变取用。应用没有计算的部分应标为 Agent 解释或尚未判断。外观里的五行筛选和颜色是用户偏好；不自动推导喜用神，也不能反过来作为强弱或取用证据。
