# 个人每日解读：把关系转成可用的提醒

类型：传统关系说明与现代行动转译。知识版本：1。本文由项目自编；十神与配对事实来自 CLI，具体行动提示是反思建议。

## 先确定是哪一层

以用户出生日干为日主，分别查看流年、流月、流日天干对应的十神。年、月、日是三个不同层次，流月月支本气还可有独立十神。保留参考日期、时分与时区；交节日内流年或流月可能变化，晚子时还涉及换日口径。

出生月令描述出生盘的时气，当下月令描述目标日期所在节月。它们不能互换。通根观察来自出生原局；流日引发的合冲需说清楚与出生哪一柱配对，不能只按生肖概括全部关系。

## 十神主题如何解释

下表是日程准备时可采用的主题，不是事件预告。十神相同的人也不会有相同经历；用户自己的安排与现实条件优先。

| 十神主题 | 可以反思的角度 | 可执行的准备 |
| --- | --- | --- |
| 比肩、劫财 | 自主、协作、界限和资源分配 | 确认谁负责什么，给合作事项设清晰边界 |
| 食神、伤官 | 表达、输出、创造和反馈 | 预演表达，准备例子，发出前复核措辞 |
| 正财、偏财 | 资源、投入、交换和优先级 | 核对时间及预算，区分必要投入与临时冲动 |
| 正官、七杀 | 责任、要求、压力和规则 | 列出验收标准、截止时间和备用方案 |
| 正印、偏印 | 学习、支持、理解和整理 | 查缺补漏，准备资料，确认可求助的人或渠道 |

若已有当前档案版本对应的旺衰解读，可把它作为有来源的分析前提，并说明该前提。没有时仍可提供上述主题与准备行动，也可比较“若偏强／若偏弱”两种条件，不要求用户必须先选择。不能为了使日笺完整而造一个旺衰结论。

## 合、冲、害

五合、六合、六冲、六害是传统配对关系。相合可作为合作与牵连的反思入口；相冲可作为变化与冲突管理的提醒；相害可引导检查沟通细节。它们不直接确定结果好坏，也不证明某个同事、家人会伤害用户。

遇到多个关系，先保留真实柱位和层次，再挑与当前问题有关的部分解释。没有必要把所有术语都扩写成断语。合不自动等于合化；冲不自动等于破坏；没有关系也不代表当天没有重要事情。

## 一份日笺的组织

从实际安排开始，例如面试、出行、复盘或休息。随后简短说明相关历法和传统关系，最后给出具体准备。可以包含：今日重点、关系依据、两三项行动、晚间可回顾的问题。

“今天七杀，所以一定有压力”不如“流日天干相对日主为七杀；可把这份传统关系当成检查要求与责任的提醒。你今天有面试，先核对岗位要求并准备两段项目例子”。后一句的面试必须来自用户或日程，不能从命盘推断。

保存日笺时关联目标民用日期和档案版本，并标为 Agent 撰写。提醒由日程接口另行创建，正文出现“记得”不代表通知已设置。旧分析过期时不要继续把它作为最新结论引用。
