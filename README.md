# 灵性日历 · v0.5.0

SwiftUI + AppKit 原生 Mac 应用。看日历、安排日程、了解民俗，与桌面伙伴「阿灵」聊一聊。

## 运行

双击 `build/灵性日历.app`。也可重新构建：

```sh
./scripts/build-app.sh
open build/灵性日历.app
```

要求 macOS 14+、Swift 6.0+；开发验证环境为 Apple Silicon、macOS 26.6.2、Swift 6.3.3。只有 Command Line Tools 也可构建；历法运行库随源码以 MIT 许可收录，无需下载运行时依赖，也不需要安装 Python。当前包采用本机 ad-hoc 签名，尚未用于公开分发或公证。

## 目前可以做什么

- **月／周／日视图**：农历、节气、年日干支；24 小时时间轴、传统时辰、全天区、重叠排列、跨日裁切、空闲时段。
- **安排日程**：双击时段新建，拖动后进入编辑器确认，保存前检查冲突；本地每天／每周重复。
- **Apple 日历**：独立授权、选择来源、查看系统事件、选择可写日历新建、普通项目直接编辑删除；已有重复事件仅操作本次。
- **Apple 提醒事项**：选择清单，查看／创建／修改普通待办，截止日期或不设期限，完成与恢复。
- **待办看板**：逾期、今天、接下来、不设期限、已完成；搜索、来源过滤、「安排时间」。
- **通知**：本地项目提醒、稍后 10 分钟／1 小时、通知中完成待办、测试通知。Apple 来源由系统应用提醒。
- **阿灵**：可拖动／隐藏的桌面宠物、本地中文时间解析、可编辑草稿、分层建议；可选远程 AI 对话。
- **命盘详情**：四柱、日主、五行、天干十神、藏干与副星、纳音、星运、自坐、旬空；术语可点击解释。
- **本地出生档案**：多档案新建、编辑、删除与切换，公历生日、当地钟表时间、IANA 时区；零点／23 点换日可选，时间不详保留候选盘。
- **大运与流年**：补齐出生时刻及排运所用性别后，查看起运、十步大运、流年与十二节月，并跳回相应日历日期。
- **个人每日解读**：参考时刻的流年／流月／流日十神，出生月令、当下月气、同类与根气线索，流日对各柱的五合、六合、六冲、六害。可比较「按身强／按身弱／未确定」假设，获得具体行动建议。
- **黄历与时辰**：日、时宜忌，值神、冲煞、传统方位、九星等规则字段；民俗分类与实际建议分开。节日和神诞目录扩展到 24 条，逐条标注地域和来源。
- **更广的节气范围**：月历节气与四柱共用本地太阳交节算法，支持 1901–2099 年；四柱按立春和十二节的交接时刻换年换月。
- **外部 Agent 接入**：随应用提供 `lingxi` CLI 与 Skill，可查档案、命盘、大运、日历和知识，并通过应用业务接口操作日程、日记与解读。
- **日笺与分析回写**：保留作者、来源和所依据的档案版本；外部 Agent 可以保存带依据的旺衰倾向，没有手动覆盖时自动用于每日解读，出生资料修改后旧分析标为过期。

## 查看自己的八字

从月历右侧「每日四柱」或侧栏「四柱与八字」进入，点击「新建档案」。填写姓名或称呼、公历生日、已知的出生时刻及出生时区。出生地只作备注，当前不校正真太阳时。仅查看命盘与每日关系无需填写性别；大运另需准确出生时刻和明确选择排运所用性别。

页面分为「我的命盘」「大运流年」「每日解读」「黄历时辰」。在每日解读中选择日期与参考时分，观察这一天如何对应自己的日主。不必先填写身强身弱；外部 Agent 保存分析后，应用可采用符合当前档案版本的最新结论，并显示依据入口。仍可临时比较不同假设，或在档案中手动指定。程序不会凭五行数量自动判断身强身弱，也不会给好运百分比。

出生时分未知时不补造时柱；遇到交节或换日边界，显示多个可能命盘并暂停单一日运解读。缺少起运必要资料时保留命盘已有内容。合、冲、害是传统配对，不直接等同吉凶。术语解释和行动提示来自本地规则，不需要远程 AI。[v0.4 排盘与解读说明](docs/bazi-v0.4.md)

## 让自己的 Agent 使用灵性日历

先打开应用，再把随包 CLI 和 Skill 的路径交给能在这台 Mac 上执行命令的 Agent：

```sh
build/灵性日历.app/Contents/MacOS/lingxi status
build/灵性日历.app/Contents/MacOS/lingxi capabilities
build/灵性日历.app/Contents/MacOS/lingxi skill path
```

Skill 名为 `lingxi-calendar`，随包在 `Contents/Resources/AgentSkill`；可按所用 Agent 的加载方式读取，不会自动安装到全局目录。业务命令默认返回 JSON，先查确定性盘面，再按需查询内置知识，最后回写分析或执行日程操作。CLI 通过本机接口调用正在运行的应用，不直接编辑数据文件。

例如让自己的 Agent：“结合我的命盘与明天安排，写一份日笺，并提前提醒我准备面试。”读取、保存解读与设置提醒均有明确返回结果。写入必须带固定重试编号，更新或删除还需当前记录版本，避免重复创建或覆盖窗口里的新修改。

旺衰可以由外部 Agent 按月令、根气和全局证据给出偏强、偏弱或未定，并保存理由及档案版本。应用优先采用用户手动指定的偏强／偏弱；没有手动覆盖时采用最新、版本匹配的 Agent 结论。旧分析不会因资料更新自动变成新结论。应用没有把五行数量评分当作完整自动旺衰算法。日记按需读取，不默认加入每次分析。首版没有新增内置 Agent 运行框架或云端远程入口。[CLI、Skill 与回写说明](docs/cli-v0.5.md)

## 连接你的日历

1. 打开侧边栏「日历与清单来源」。
2. 分别连接「Apple 日历」「提醒事项」，在系统提示中选择是否允许。
3. 在「新建日程默认保存到」选择一个可写 Apple 日历；提醒事项有独立默认位置。之后的新建和阿灵草稿使用该位置。
4. 勾选想显示的其他来源；设为默认或保存到某个来源时，该来源会自动显示。
5. 已有本地日程不会自动上传。打开它，在「保存到」选择 Apple，点击「转入 Apple 日历」并确认。系统写入成功后移除本地副本；之后的修改写回 Apple。

选择「仅灵性日历（本地）」的事项不会出现在 Apple 应用中。编辑器会明确标出保存位置；可勾选记住该位置。默认来源失效时提示重新选择，不会悄悄改存本地。已有 Apple 事项不支持跨日历移动。

macOS 读取 EventKit 日历要求完整访问；应用仅在你明确保存、删除或完成时修改。含参与者的会议、只读来源和复杂重复提醒事项请在 Apple 应用中管理。出现外部修改冲突时会拒绝覆盖，需刷新并重新打开。

系统同步依赖你在 macOS 配置的账户与网络；本应用不会把系统事件复制进本地 JSON。详见 [Apple 接入说明](docs/apple-integration.md)。

## 试一试

在阿灵中输入：

- `提醒我明天下午三点开会`
- `提醒我下周一上午九点面试，持续90分钟，提前30分钟提醒`
- `每天晚上八点阅读，不用提醒`

识别后先显示草稿及保存位置，确认后写入所选默认日历；可点击「修改」单独选择位置。遇到时间冲突会进入编辑器确认。缺日期或时间时追问，补充信息需重新组成完整一句话。

`⌘N` 新建，`⌘J` 阿灵，`⌘,` 设置。桌面阿灵头顶 `···` 可拖动；隐藏后从菜单栏唤回。关闭主窗口后仍留在菜单栏，`⌘Q` 完全退出。

## 数据与范围

本地文件：`~/Library/Application Support/LingxingCalendar/events.json`。原子写入、兼容 v0.1 数据；损坏文件不会自动覆盖，原有系统通知也不会因读取失败被清掉。

出生档案单独保存在同目录的 `profiles.json`，损坏时保留原文件并停止写入。旧档案无需重建；新增加的排运性别和旺衰假设默认为未填写。档案、命盘和个人解读不会自动发送到云端聊天。

日记与分析保存在同目录的 `notes.json`，同样采用校验后的原子写入。Agent 写入带来源和作者；与命盘关联的记录可保留 `profileRevision`，档案改动后提示重新分析。应用不会自动将这些记录提交给任何模型；外部 Agent 经 CLI 读取后，内容的后续处理取决于用户所用 Agent 及其配置。

民用月历和日程使用 Asia/Shanghai。月历年干支春节换年，日干支零点换日；节气支持 1901–2099 年，2025–2027 年的 72 个日期已对照香港天文台。四柱在立春交接瞬间换年，黄历部分字段按交节日期切换，页面分别说明口径。不能把节气日期标注当作当天凌晨已交节，也不能把黄历分类当作个人吉凶结论。[历法来源](docs/calendar-sources.md)

本地重复项目整组编辑／删除，重复待办完成也影响整个系列。暂不拖动本地重复实例。空闲与冲突依据已显示来源；候选重复事件只检查本次时段。

常规本地通知安排未来 30 天内最早 52 条，与稍后提醒合计最多 60 条；每 30 分钟及应用激活时补充。退出后仅已安排的通知有效。实际送达需要通知权限，可能受专注模式影响。

默认不联网。可选远程对话使用兼容 Chat Completions 的 HTTPS 地址、模型与 API 密钥，密钥存于钥匙串；聊天只保留在内存。系统来源上下文默认不发送给模型，需单独启用。当前 AI 没有完整工具调用循环，创建操作由本地解析器和用户确认驱动。

## 开发与验收

```sh
./scripts/test.sh
./scripts/test-apple-codec.sh
./scripts/build-preview.sh
open build/灵性日历预览.app
python3 scripts/test-cli-integration.py
./scripts/build-app.sh
```

CLI 集成检查需预览应用已启动，只向 `--preview` 写入合成资料并在结束时清理；不会回退到正式应用。受限运行环境若禁止 Unix socket，需在允许本机 IPC 的环境运行这组检查。

核心测试包含历法、四柱与大运边界、出生档案、命盘详情、个人解读、日时黄历，以及既有日程与提醒；最新数量见[验收记录](docs/verification.md)。预览包与正式包使用不同 bundle ID、不同本地文件；合成数据使用 `build/preview-events.json`、`build/preview-profiles.json` 和 `build/preview-notes.json`，不发送通知。CLI 使用 `--preview` 连接预览环境，连接失败不会退回正式应用。真实 Apple 账户写入／跨设备同步、系统通知送达和远程模型对话，仍需在相应权限与服务配置后验收。

`Sources/LingxiCore` 是计算、持久化与本机接口共享类型；`Sources/LingxiApp` 是 SwiftUI 界面及系统适配；`Sources/LingxiCLI` 是命令行入口。完整 Xcode 可打开 `Package.swift`；建议使用脚本生成 `.app` 进行交互验证。
