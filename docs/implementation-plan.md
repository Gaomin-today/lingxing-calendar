# 灵性日历：第一版范围与实现方案

> 此文保留初版规划。2026-09-17 已完成 v0.1 本地闭环和 v0.2 第一批增强；当前实现边界见 [第一批说明](first-batch-v0.2.md)，验收情况见 [验证记录](verification.md)。下文第二阶段的 Apple EventKit 接入已在 v0.2 实现，真实账户行为仍待用户连接后验收。

## 项目检查（2026-09-17）

项目仅有空目录，没有已有业务代码、依赖或历史数据。当前环境为 Apple Silicon，Swift 6.3.3、macOS SDK 可用；没有完整 Xcode。采用 Swift Package + SwiftUI + AppKit，脚本打包为本机可运行的 `.app`，不引入网页容器。

## 第一阶段：本地闭环

- 月历：公历与农历、今天定位、月份切换、选日详情。历法固定北京时间，明确展示时区与换年口径。
- 资料：传统节日与部分神诞；每条民俗资料附适用传统、地域、来源链接。节气只展示已核实年份的数据。
- 日程：本地创建、编辑、删除、全天、每日/每周重复、待办完成状态。重复系列第一版整体编辑/删除。
- 提醒：系统 UserNotifications；首次使用时请求权限。按未来窗口安排本机提醒，并说明应用退出后的覆盖期限。
- 小助手「阿灵」：AppKit 浮动透明窗口，可拖动、可隐藏；支持主窗口和菜单栏重新唤起。
- 对话：本地中文解析时间，先呈现可编辑日程草稿，确认后写入；选日与事件提供分层建议。离线功能无需密钥；可选连接兼容 Chat Completions 的 HTTPS 服务进行对话。
- 视觉：米白底、青绿主色、朱砂点缀、东方书卷感，信息层级保持清楚。不向空白日历注入虚构用户日程。

## 边界与可信度

历法计算与事件写入由确定性代码执行，模型无权自行改历法或执行删除。缺少日期或时间时追问。民俗建议与实际准备分开显示。未接入可靠黄历版本前不展示伪造的每日/时辰吉凶，不宣称占卜预测结果。

数据保存于 Application Support/LingxingCalendar/events.json，原子写入；损坏文件不自动覆盖。远程聊天仅由用户启用、配置后发送，发送选日信息与该日程标题作为上下文；凭据存于 macOS 钥匙串。

## 模块

`LingxiCore`：CalendarEngine / FestivalCatalog / EventRepository / EventScheduler / NaturalLanguageParser / AdviceEngine。纯 Foundation，可单元测试。

`LingxiApp`：SwiftUI 月历、详情、日程编辑器、对话、设置；AppStore 状态与写入入口；AppKit 桌面助手和菜单栏；通知和可选远程对话适配器。

## 第二阶段

Apple EventKit 同步（先只读后双向、处理权限和冲突）、独立重复实例与结束日期、更多节气年份及权威历法交叉校验、节日/神诞订阅提醒、搜索和导出。

## 第三阶段

带结构化工具协议的多轮 Agent；更全面的时间表达和时区旅行场景；可选择出处与流派的黄历资料；宠物性格、动画与明确标为自我探索的卦象体验。

## 验证

历法参考日期和闰月、自然语言歧义与过去时间、持久化和文件损坏、跨月重复和提醒排序采用单元测试。原生 `.app` 构建后进行界面检查与日程创建/编辑/删除、助手窗口验证。系统通知实际送达受系统授权与专注模式影响，不能仅用调度成功推断送达。
