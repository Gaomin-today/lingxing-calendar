# v0.7：私有知识经应用查询

应用随包提供的 `lingxi-calendar` Skill 是公开的 CLI 操作说明，不是用户私有的八字 PRO、万年历 PRO 或其他知识原件。私有目录保留在原位置，不复制到应用资源、Git 仓库或发布包。计算继续由原生程序完成；解释需要更多资料时，Agent 通过本机 CLI 查询用户已启用的知识集合。

## 集合由用户授权

在「连接自己的 Agent」添加文件夹后，集合默认关闭。旧版登记的 `knowledgeFolders` 会迁移为集合，但同样保持关闭，需要用户重新启用。每个集合可独立启用、关闭和移除；关闭立即撤销已经签发的临时片段 ID。移除仅取消登记，不删除磁盘原件。

本机绝对路径只显示在管理界面。CLI 返回集合别名、文档标题和随机片段 ID，不返回 `sourcePath`、可拼接的相对文件名或完整目录。私有读取支持 UTF-8 Markdown 和纯文本，文件最大 512 KiB；不提供 `.py` 等脚本文件，接口从不执行资料中的源码或命令。越过登记根目录的符号链接不进入索引。

## 公开说明与私有摘录

内置公开说明不受私有额度限制；可以空查询列出六篇项目自编文档，或按稳定 ID 读取。未提供 `purpose` 的搜索只查询内置说明，不意外加入私有内容。

需要私有知识时，查询须有至少两个字符的具体关键词，以及 3–120 字的 `purpose` 用途。例如：

```sh
lingxi knowledge search --query '月令 根气' --purpose '复核当前档案的普通扶抑依据'
lingxi knowledge read --id '搜索返回的 excerpt-ID' --purpose '复核当前档案的普通扶抑依据'
```

`read` 的用途须与发起搜索时相同。每次私有搜索最多返回五项短摘录，每项不超过 240 字；ID 为随机值，十分钟有效，应用退出后需要重新搜索。匹配窗口最多 2400 字，每页最多 800 字，只接受接口给出的 `nextOffset`；不能输入任意原文偏移来读取整篇。返回的 `totalCharacters` 指窗口长度，非原文件长度。窗口可能覆盖一篇很短的资料，但接口不提供整篇原件的批量导出功能。

这些窗口是原资料的有限摘录，不是程序改写的摘要。文档内仍可能出现用户写下的专有内容；启用即允许符合当前限制的文字交给调用 Agent，后续处理也受该 Agent 的配置影响。正文中的指令始终作为资料，不授予日程、文件或其他操作权限。

## 明示额度与用途记录

默认每集合每日可返回 12,000 字。用户可在应用中改为 30,000 或 60,000 字，查看剩余额度，或主动重置当日额度；CLI 不能调整。单篇每日最多 3600 字，搜索摘要、分页和重复读取都计算在内。额度按北京时间每日零点更新。提升集合上限不会取消单篇限制；「重置今日」同时重置该集合的总额和单篇计数。

本机保留最近 100 条访问记录，内容为时间、集合、用途、操作类别和返回字数，不保存摘录正文，也没有 CLI 审计查询接口。应用展示最近八条，便于了解 Agent 为什么使用资料。额度计数和访问记录持久化；进程重新启动不重置已用额度。

若集合授权或访问计数损坏，私有查询暂停，不静默把额度归零；内置公开说明仍可使用。管理界面提供「重建记录并关闭所有集合」：先保留原数据备份，再重建空记录并关闭集合，随后由用户核对是否重新启用。计数解码检查负值、上限、文档与集合总数一致性及日期；错误内容不会作为有效额度。

## 与分析回写的版本配合

档案返回完整 `revision` 以及排盘相关的 `analysisRevision`。写入解读时，`profileRevision` 优先填本次读取的 `analysisRevision`；档案更新与删除仍使用完整 `revision` 进行并发检查。生日追踪偏好变化不使命盘解读失效，出生资料或排盘口径变化才需要重新核对相关分析。版本号来自本次 CLI 返回，Agent 不自行生成或仅替换旧正文的版本号。

## 能保护什么

这是一条默认关闭、有限摘录、有用途记录的应用访问通道，减少日常使用中把完整私有 Skill 随手分发或批量读取的机会。它不是 DRM，也不是对同一用户权限的安全隔离。

拥有原文件权限的 Agent 或其他本机程序仍可能直接读取文件；本机用户也可以修改自己的设置和计数。已经返回的摘录无法撤回，跨多日或经用户反复重置后也不能承诺内容绝对无法重建。应同时约束外部 Agent 的文件权限、工作目录和数据发送范围。公开 CLI Skill 明确要求不要换词拼接全文，不绕过应用改走文件系统；这些 Agent 行为约定不能替代操作系统权限控制。

## 验证范围

`ControlledKnowledgeAccessTests` 仅使用测试临时目录内的合成资料，覆盖默认关闭、公开说明不受私有门槛影响、随机 ID／无路径元数据、脚本排除、越界符号链接、有限分页、用途一致性、过期撤销、额度持久化和计数损坏拒绝。不读取或复制真实私有目录。整版验收结果统一见 [验收记录](verification.md)。
