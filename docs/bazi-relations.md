# 流日与命盘关系：规则、来源与范围

核查日期：2026-09-17。实现：`Sources/LingxiCore/BaziRelationshipEngine.swift`。

## 来源口径

主来源采用明代万民英《三命通会》的维基文库原典转录：[四库全书本卷二](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷02)、[四库全书本卷五](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷05)。另对照[普通分卷本卷二](https://zh.wikisource.org/wiki/三命通會/卷二)中的配对文字。这些链接证明规则出自传统术数文献，不构成预测有效性的证据。

转录存在己／巳、戌／戍等字形混淆，编码按天干与地支各自的上下文及对照文本统一，不照录错误字形。本次没有完成古籍影印本逐字校勘，不将网络转录标记为经过全面校勘的版本。

[《渊海子平》页面](https://zh.wikisource.org/wiki/淵海子平)列有清楚的甲、乙日主十神表，可作交叉核对；但该页带有“来源不明”维护模板，因此不作为产品主来源。

十神以**出生的日柱天干**为日主，只计算**流日的天干**与它的关系。木、火、土、金、水按相生次序排列；相生前进一位、相克前进两位。天干顺序甲乙丙丁戊己庚辛壬癸，零起始偶数为阳、奇数为阴。

以上是对原典基础分类的确定性编码；不移植原典中的婚姻、性别、寿夭、疾病或人格高下断语。六害仅记录无向配对，不复用原典部分段落中的方向性灾福断语。

## 展示与解释

每一条命中都保存完整流日、命盘柱名、柱位序号和配对。例如：`流日甲子 ↔ 年柱己丑：甲己合`，以及同一对柱的 `子丑合`。相同干支出现在不同柱上时分别保留，不合并成笼统的“今天与你相合”。未知时柱不补造。

将古籍配对规则用于“流日与出生四柱”的逐项核对，是本产品的展示方式；不声称它构成古籍中一套完整的每日运势模型。

概览标签是产品的归纳：只有合为“相合”，只有冲为“相冲”，只有害为“相害”，多类同时出现为“并见”，本批规则均未命中为“平和”。这里的“平和”只表示未命中，不能理解为当天必然顺利。多个合不累加成吉分，多个冲害不累加成凶分。

合不等于吉，也不等于已经合化；冲不等于凶。《三命通会》卷二〈论冲击〉本身就要求区分冲的不同作用。本批不计算月令旺衰、喜忌用神或格局，所以不据此给出“宜签约”“不宜出行”等结果性判断。

每项 `reflection` 是产品撰写的现代行动提示，例如核对约定、明确分工、留出时间缓冲；它们不是古籍原文，也不是关于事件将会发生的断言。

## API 与验证

```swift
let report = try BaziRelationshipEngine().analyze(
    dayMasterStemIndex: 1,
    flowDay: BaziRelationInput(label: "流日", stemIndex: 0, branchIndex: 0),
    pillars: [
        BaziRelationInput(label: "年柱", stemIndex: 5, branchIndex: 1),
        BaziRelationInput(label: "月柱", stemIndex: 2, branchIndex: 6),
        BaziRelationInput(label: "日柱", stemIndex: 1, branchIndex: 7)
    ]
)
```

日期、节气分界、出生时区和四柱排盘由调用方负责；本模块不读取用户资料、不访问网络、不调用模型。输入索引越界、干支阴阳不匹配或完全缺少命盘柱位时显式报错。

`BaziRelationshipTests` 覆盖全部 100 个十神组合、100 个天干配对、144 个地支配对及其未命中情况；另检验具体柱位归属、重复柱、缺失时柱、概览标签、来源字段和非法输入。未实现三刑、自刑、三合、半合、破、藏干、旺衰用神及吉凶评分。
