# v0.6：个人首页、河洛卦与外观

本版让出生资料成为日常使用的起点。打开「我的今天」，先看到个人当日信息和实际安排；需要深入时再进入命盘、卦象细节或外部 Agent 任务。

## 个人首页

首页组合以下内容：

- 选中日期的农历、节气及节日，可切前后一天、直接选择日期或返回今天。
- 当前档案的今日河洛卦，进入详情查看先后天、年／月／日卦与有效时段。
- 日主对应的流日十神、当下流月及行动角度；旺衰显示当前采用的来源，并提供依据入口。
- 当天日程与待办、根据具体安排生成的准备提示，以及关联该日期和档案的日笺。

未建档时提供建档入口；未知时刻仍可保存档案，界面保留缺项和候选盘，不补造个人结论。主页以所选日北京时间正午为参考，不等于全天所有时辰相同；详细每日解读可调整参考时分。

## 旺衰不再依赖先手选

本地 `ordinary-fuyi-v1.0` 普通扶抑规则读取出生原局的月令、透干、通根、生扶和泄耗克。报告并列支持依据、反证与不确定条件，不以五行数量相加给分。月令、根气和透干未形成一致方向，或资料／结构需要复核时显示未定；未定不等于中和。

当前解读前提按顺序采用：

1. 用户在档案明确设定的偏强或偏弱。
2. 与当前档案版本匹配、最近更新的 Agent 旺衰分析。有效的“未定”也保留。
3. 本地规则初判。

本地报告始终可查看，即使手动设定或 Agent 分析正优先生效。手动对比仍放在高级选项，修改出生资料后旧 Agent 结论过期。本地初判没有完成调候、格局、司令分日或喜用神系统；不会自动推荐命理“必选”配色。相关依据也供 CLI 和外部 Agent 查询。[CLI 与回写说明](cli-v0.5.md)

## 每天快速看到自己的卦

河洛报告包含先天卦、后天卦、元堂、值年、值月、值日、当前爻和先后天岁序。需要已知出生时刻与明确填写的排盘性别。首页重点呈现今日卦，细节处保留其余层次和简短术语解释。

查询日期与参考时分使用北京时间；河洛自然日按出生档案时区零点推进。年卦随立春、月卦随十二节精确交界。交节当天可能有两个不同的月卦／日卦，展示取值时刻和有效区间。缺项、出生前或超出覆盖范围时明确保留空缺，不回退到别的日期冒充当前结果。

原参考脚本的算法数表可复用，但其边界行为并非全部照搬。本版统一立春年岁序、修正跨年小寒及交节日分段，详见 [河洛规则与验证](heluo-v0.6.md)。卦名与爻画是计算结果；主题与反思提示是本应用原创短文，不是古籍原文，也不承诺事件预测。

## 交给自己的 Agent

日期、命盘、日程旁的「交给我的 Agent」打开一份可核对的完整任务。里面包含本机 CLI／Skill 路径、目标日期和档案或事项 ID、北京时间参考时分、读取命令、保存日笺的选择及用户补充要求。卦象页选中的时分也会保留。复制后仍需发送给自己的 Agent；应用没有因此启动内置 Agent、发送私人资料或执行任何日程操作。

能在本机执行命令的 Agent 可按 Skill 读取计算结果及授权知识，再按任务要求回写。分析回写后显示作者、依据和档案版本；过期记录有标记。本版新增 `strength show`、`hexagrams show`，组合 `context` 同时含本地旺衰报告及河洛结果。原有版本冲突和请求防重规则继续适用，Apple 来源仍只由 CLI 读取。

## 六位灵宠

| 灵宠 | 造型 | 外观分类 |
| --- | --- | --- |
| 青芽 | 长着嫩芽的圆形精灵 | 木 |
| 云炉 | 双耳、有云烟的香炉 | 土、火 |
| 双子 | 成对月牙筊杯，各有神情 | 木、土 |
| 莲灯 | 莲瓣托起的一点灯火 | 火、木 |
| 玄龟 | 有几何龟甲的小龟 | 水 |
| 金铃 | 带吊环与铃舌的铃铛 | 金 |

全部使用 SwiftUI 原生矢量，适合透明桌面面板。最多勾选两项五行偏好筛选候选，也能点「全部」自由选择。筛选不会切换已选宠物；选择新宠物后桌宠、侧栏和聊天头像同步。这里的五行是造型分类和个人偏好，不是应用自动算出的喜忌组合。

## 单色或双色主题

主色影响侧栏、选中日期与按钮；辅色用于卡片底色、卦象和内容点缀。单色时沿用同一色系，双色时最多指定两种强调色。五行预设、系统取色器与六位 HEX 都可以选色，界面提供实时预览和恢复默认。过浅颜色在按钮、彩色文字上自动加深；中性纸色、正文和语义提示色保持稳定。

配色和灵宠独立选择，即时保存在本机 UserDefaults，正式与预览包各自保存。喜欢木色可以选松绿，但选色不会修改命盘或影响旺衰结果。初判未定、没有 Agent 分析或没有出生档案时也可以自由使用外观设置。
