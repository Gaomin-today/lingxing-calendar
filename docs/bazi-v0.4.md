# v0.4 命盘、大运与个人每日解读

本版把已有出生档案和四柱扩展为四个可切换的页面：**我的命盘、大运流年、每日解读、黄历时辰**。所有计算在本机完成，不需要配置远程 AI。

## 现在能做什么

| 页面 | 可以查看或操作 |
| --- | --- |
| 我的命盘 | 选择本地出生档案，查看四柱、日主与五行、天干十神、藏干与副星、纳音、星运、自坐、旬及旬空；点击术语解释规则和来源 |
| 大运流年 | 填写排运所用性别及已知出生时刻后，查看顺逆排法、起运间隔、首交运时间、十步大运、所涉流年与十二节月；跳回支持范围内的日历日期 |
| 每日解读 | 选择日历日期和参考时分，查看流年／月／日天干相对日主的十神、出生月令与当下月气、流日对原局各柱的合冲；比较身强／身弱／未确定的解读假设，得到现实行动提示 |
| 黄历时辰 | 查看日宜忌、时辰宜忌、传统值神、冲煞、方位及九星等规则字段；早子时和晚子时分开，来源与日期口径可查 |

出生档案新增两个可选字段：排运所用性别、常用旺衰解读假设。旧档案继续可读，缺少字段不会自动猜测；仅看命盘与每日关系无需填写排运性别。临时切换解读假设不会自动改写档案。

信息架构参考了[元亨利贞排盘页](https://paipan.china95.net/bazi.htm)对出生资料和排盘口径的组织，以及[农历吧排盘页](https://nongliba.cc/bazi.html)的四柱、大运、流年流月层次。这里只借鉴信息分层，不复用两站的算法、断语或界面素材，也不表示功能或预测能力与其对等。

## 时间口径

- **民用月历与日程**使用 Asia/Shanghai；生肖和农历干支年在春节换年，民用日干支在零点换日。
- **出生四柱**使用档案选定的 IANA 时区和当地钟表时间；立春的交接瞬间换年，十二节的交接瞬间换月。可选零点或 23 点换日，不做真太阳时校正。出生地仅是备注，不据地名推断经度或时区。
- **个人每日解读**使用页面所选北京时间和参考时分生成流时四柱，再以出生日干为十神参照。交节当天的年柱或月柱可能在日内变化，不能用一个公历年份或整天标签替代。
- **黄历**按北京时间民用日期查询。日黄历零点换日、月建按库的固定 UTC+8 交节日期切换；时辰使用晚子时 23 点换日。年、月九星也按库的固定 UTC+8 交节日期切换；历史夏令时期间可与民用日历的节气日期不同，示例见黄历说明。这些传统字段与精确交节四柱有各自口径，不混为同一个结果。

四柱、节气与黄历公开范围为 1901–2099 年。内部 1900、2100 数据只补齐范围端点，例如 2099 流年的丑月延续到 2100 立春；这不代表日历和出生档案开放到 2100 年。

不存在的公历日期、被时区调整跳过的日期或夏令时空缺时刻会拒绝保存。回拨导致重复时刻时，采用第一次出现的时刻并提示核对，目前不能选择第二次出现。交节算法含 ΔT 模型估计，接近交界的出生记录仍需核对；显示到分钟不代表分钟或秒级的独立观测保证。

## 缺项保持缺项

时间未知时，命盘不补造时柱。出生日期内若有交节或所选换日边界，会展示多个年月日候选；存在多个候选时暂停唯一的个人日运解读。只有一个三柱候选时可以查看三柱范围内的关系，并明确缺失时柱。

起运需要已知出生时刻和明确的排运性别。缺少其中一项时保留已有命盘，显示补充入口，不默认生成唯一交运时刻。大运表中的当前状态由一个明确的参考瞬间决定，交运日内可能先后属于两步大运。

藏干、纳音、十二长生和旬空是确定性传统表格字段。星运以日干对各支，自坐以该柱自己的天干对自己的地支；两者可能不同。长生、病、死、墓、绝等词是传统阶段名称，不能按字面视为健康或事件结论。藏干只区分本气和其他成员，列表顺序不代表固定能量比例。

## 起运与流年流月

采用固定 `lunar-swift 1.1.8` 的 `Yun sect 2` 分钟法口径，并适配绝对时刻与所选民用时区：

1. 阳年男、阴年女顺排；阴年男、阳年女逆排。年阴阳取立春年柱天干。
2. 顺数到下一个节，逆数到上一个节；按绝对分钟间隔换算，避免把夏令时钟表跳动算成额外时间。
3. 3 天折 1 年，360 分钟折 1 个月，12 分钟折 1 天，1 分钟折 2 小时。交节时刻先按参考库量化到整秒，再舍秒取分钟后相减。
4. 在出生时区中依次加年、月、日、小时得到首交运计算值。每步大运从实际交运瞬间开始，到下一交运瞬间结束；含起点、不含终点，连续十年，不按 1 月 1 日整年切断。

起运是传统换算规则，不是一个可观测天文事件；出生或交节时刻的误差会被换算放大。时间轴优先展示真实交运日期，参考岁数按交运公历年减出生公历年再加一，不作为农历虚岁或周岁计算，不能替代交运日期。

流年按立春到下一立春划分。一个十年运段通常会碰到 11 个流年，首尾流年可能只有部分时间与该大运相交。流月按立春起寅月，到小寒起丑月，共十二节月；它既不是公历整月，也不是农历月份。超出支持年份的流年不推算。

## 旺衰背景与每日解读

程序**不会自动判定身强身弱**。用户选择的是普通扶抑法的解读假设，不是体能、心理能力或好运等级。在未确定时，先展示十神主题和可核对的命局线索。

命局观察包括出生月支本气与日主的生克关系、其他天干的同类和生扶、已知各柱藏干中的同五行根气。每条都保留具体位置；不把日干自身重复算入同类，不给五行数量加权计分，也不将“未见同类藏干”直接判成无根或身弱。月支本气只是月令的一条线索，尤其不能用单个土元素概括辰戌丑未整月的司令。

流年、流月、流日分别计算天干十神，流月天干与月支本气的十神分别展示。强弱假设只改变条件性解释和行动角度，不改变历法、十神或合冲事实。合、冲、害保留真实配对和出生柱位，不直接判为吉凶；不会输出好运百分比或具体事件概率。

本版尚未综合格局、调候、从化、合化、根气受损与大运来确定旺衰喜用。大运表和每日解读可以共同查看，但不能称为已经完成全局命断。建议是现代自我反思与日程准备提示，不承诺预测结果。详细规则见 [个人解读说明](personal-reading-v0.4.md) 与 [传统关系来源](bazi-relations.md)。

## 来源、迁移与隐私

运行库固定为 [lunar-swift 1.1.8](https://github.com/6tail/lunar-swift/tree/a7ec0e9b29f84a5d98b09b9ffd31145f17470d56)，MIT 许可随源码及应用包保留。四柱的太阳交节仍由原有引擎负责；新增表格和黄历使用收录的完整运行库，没有把本地时间重新当成另一时区回灌排盘。

用户提供的 `bazi-pro` 和 `wannianli-pro` 保留在 `LocalReferenceSkills/` 供阅读、核查和生成合成回归样例，不进入 `.app` 或 Git。应用不需要 Python，也不自动运行技能脚本。尤其没有迁入技能中按人为五行权重或月令单项直接判断身旺的启发式，也没有迁入吉凶事件断语。迁移背景及原件校验记录见 [v0.3 记录](bazi-v0.3.md)。

出生资料单独存于 `profiles.json`，与日程和 API 设置分开；先持久化成功再更新内存，损坏文件保留并停止覆盖。命盘、排运性别、旺衰假设和个人解读不自动进入阿灵的云端上下文。预览使用独立合成档案，不写真实出生资料或系统日历。

## 验证范围

新增测试覆盖命盘详情与六十甲子表、已知和未知时刻、晚子时、起运分钟换算、跨时区同一瞬间、夏令时、闰日交运、连续十年边界、立春流年、十二节月和最后支持年份。个人解读验证三层十神、十二月支本气、根气归属及强弱假设不污染事实；黄历对照用户实际主引擎生成的合成日／时样例。

这些跨语言样例证明本次规则口径的兼容性，不等于独立验证古籍预测，也不能替代天文精度核验。最终测试数量、Release 构建和 UI 实测记录统一见 [验收记录](verification.md)。本版目标版本为 **0.4.0（build 5）**。
