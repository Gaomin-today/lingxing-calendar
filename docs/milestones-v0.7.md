# 倒计时、纪念日与生日（v0.7）

这是本地首页日期提醒，不创建日历日程，不发送系统通知。生日按档案逐个明确选入；新档案、旧档案和未填写设置的档案一律默认关闭。

## 日期口径

- 与首页一致，按 Asia/Shanghai 的北京时间公历自然日计数；不随 Mac 的当前时区变化。界面显示作为基准的选中日期，避免把查看历史日期误认成实时倒计时。
- 单次倒计时：未来显示“还有 N 天”，当天显示“就是今天”，过去保留“已过 N 天”。单次纪念日过去显示“已经 N 天”。这些天数不含额外人为加一。
- 每年重复：寻找大于等于选中日的下一次公历月日；不会在原始目标日期之前虚构一轮纪念日。2 月 29 日在非闰年按 2 月 28 日，并显示该规则。
- 公历生日：按档案里填写的民用出生月日，不把生日时刻转换到北京时间再改变生日。不需要准确出生时刻。
- 农历生日：用所填公历出生日期经应用内 LunarSwift 换算为中国农历月日。普通月出生只过普通月；闰月出生在有对应闰月的年份过该闰月，否则过同序普通月。三十遇 29 天的小月，按该月末日。界面说明实际发生的调整。
- 生日只在选中日期不早于该档案出生日期时出现。农历生日依赖中国农历日期规则，不根据出生地额外推导另一套地域阴历。
- 输入和目标输出限 1901–2099 年；下一轮超过范围时显示原因，不悄悄改成其他日期。

## 保存与版本

`MilestoneRepository` 使用独立 `milestones.json`；预览由调用者传入预览专用路径，不能回退到真实用户文件。保存前验证字段和唯一标识，写入采用原子替换；已有文件损坏时拒绝覆盖。`MilestoneStore` 在写入前确认磁盘快照和内存一致；编辑及删除携带原始记录，拒绝覆盖中途的新改动。

生日设置为 `BirthProfile.birthdayTracking`，可选值 `solar`、`lunar`，缺省或 `null` 为关闭。完整档案版本用于并发保护，仍随生日设置变动而改变；`BirthProfile.analysisRevision()` 在求版本前排除生日设置，使仅开关首页生日不会让已有命盘解读失效。旧档案的分析版本与原完整版本一致。

## 核验样例（全部合成）

| 出生日期与选择 | 首页选中日 | 应显示 |
| --- | --- | --- |
| 2000-09-18，公历 | 2026-09-18 | 生日当天 |
| 2000-02-05，农历正月初一 | 2026-02-16 | 距 2026-02-17 还有 1 天 |
| 2000-02-29，公历 | 2026-02-28 | 生日当天，并说明非闰年按 2 月 28 日 |
| 2023-03-22，农历闰二月初一 | 2026-01-01 | 2026-03-19，说明无对应闰月按普通二月 |
| 2023-03-22，农历闰二月初一 | 2042-01-01 | 2042-03-22（当年对应闰二月） |
| 1995-01-30，农历腊月三十 | 2026-01-01 | 2026-02-16，说明当月只有 29 天按月末 |

农历样例另经开发用 lunar_python 1.4.8 交叉核验。应用运行不需要 Python，不含真实用户出生资料。
