# 本地旺衰初判 v1

规则标识：`ordinary-fuyi-v1.0`。这是灵性日历公开的保守分类口径，用于普通扶抑初步筛查；不是各流派公认的统一算法。结果只有「偏强初判」「偏弱初判」「暂未确定」，不把未定改称中和，不生成概率、旺衰总分、喜用神或吉凶分。

## 输入与报告

```swift
let report = StrengthAssessmentEngine().analyze(charts: natalCharts, profile: birthProfile)
// 单个已确认盘也可使用 analyze(natal: chart)
```

输入必须是同一档案通过 `FourPillarsEngine` 算出的完整候选盘集合。引擎不重新猜测时辰、不以当日干支改动原局。档案姓名、地点备注、性别和手选旺衰不参与计算。传入档案时验证民用出生资料及夏令时重复时刻；出生时刻未知、时柱缺失、多组候选盘、无盘或临近交节均保留未定。10 分钟的交节复核窗口属于产品规则，不是历法的误差估计。

`StrengthAssessmentReport` 为 Codable，包含规则版本、`assessment`、`label`、`summary`、`decisionID`、日主、候选数、六类证据、反证、不确定原因、适用范围、限制和数据来源。证据保留具体柱位、天干、藏干与本气/其他藏干区别。多候选盘不展示随意选择的第一盘证据，候选顺序不改变报告。

## 决策次序

1. **月令**：使用本项目固定版本的藏干表，按月支本气对日主的生克关系观察。月令来自节气月。辰、戌、丑、未暂不分类，因为 v1 未处理分日司令、杂气透出及燥湿土性。
2. **天干与透出**：除日干外逐柱记录天干十神，并寻找原局哪些地支藏有同一天干。可见不等于有力；相同五行、相反阴阳不冒充同干透出。
3. **根气**：藏干与日干同五行即记为根气线索，允许阴阳不同。本气根与其他藏干根分开，所有柱位均保留。
4. **生扶与泄耗克**：印比为生扶方向，食伤为泄、财为耗、官杀为克。它们不互相折成等价的数值。
5. **结构暂停条件**：见日干与其他天干五合、完整三合/三会组合、涉及月令或根气地支的六冲，先暂停定性。这只是关系存在，不宣称合化成功、成局或根气消失。原局未见任何根气、透干生扶及地支本气生扶，或天干及所有地支本气均集中于印比，也暂停以排除从格、专旺等结构。
6. **一致性判定**：以上无暂停项时，满足下面一条才给倾向，否则未定。

| 倾向 | 必须同时满足的可审计条件 |
| --- | --- |
| 偏强 | 月令本气为同类或生扶；至少有一处本气根；至少有一处日干之外的透干印比；透干泄耗克位置不超过一处 |
| 偏弱 | 月令本气为泄耗克；没有本气根；其他藏干根不超过一处；至少两处日干之外的透干为泄耗克 |

位置数量只作为保守筛查的门槛，不相加成力量分数。门槛是本产品选择，不能表述为古籍给出的定量标准。季节支持而透干反向、季节不支持但根与印比充分等矛盾结构保留未定。

偏强时展示泄耗克及「月令为印而非同类」等反证；偏弱时展示印比和其他藏干根等反证。暂停判断也保留已知根气事实，不以一个合冲把原始事实删掉。

## 适用范围

这是传统文化解释层，不是历法事实或科学测量。强弱不指体能、心理能力、人格优劣或生活成败。v1 未建立完整的格局、调候、病药通关、司令分日、合化条件、刑害破和制化模型；需要这些模型才能确定的盘应保留未定。自动结论可作为每日普通扶抑提示的默认前提，用户手动设定或有效 Agent 分析覆盖时应明确标注来源，并允许查看这份独立的本地报告。

出生资料变化后重新计算，不能延用旧资料的初判。颜色和灵宠属于个人偏好与文化联想，不能从这份旺衰倾向直接推出用户喜忌用神。

## 参考与实现关系

- 藏干和十神事实复用本项目固定的 [lunar-swift 1.1.8](https://github.com/6tail/lunar-swift/tree/a7ec0e9b29f84a5d98b09b9ffd31145f17470d56) 数据。
- 月令与整体生扶泄耗的传统背景可对照 [《三命通会》卷七·子平说辩](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷07)。现代规则门槛由本项目自行定义，没有将该书的宿命断语带入产品。
- 参考用户提供的 bazi-pro 分析流程：先月令、透干、根气与整体结构；不得照抄脚本的简化 `yong_shen_reference`，不得仅数五行数量。私有资料不随本功能发布。

## 验证

合成结构测试覆盖：相互支持的三组证据、偏弱仍有生扶反证、同样五行数量但月令位置不同、月令与透干矛盾、未知时柱、多候选顺序不变、异阴阳藏干根、日干不自计、杂气月、五合与三合及根冲、从格排除、节气边界、资料校验和夏令时重复时刻、手动前提/姓名等不改变自动报告、Codable 往返。

这些测试验证程序忠实执行已公开的规则及退让边界，不构成对命理预测能力的验证。
